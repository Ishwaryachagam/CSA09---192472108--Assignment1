# CSA09 – Campus Smart-Parking System

## Project Overview
This project demonstrates Java programming and Object-Oriented Programming (OOP) concepts through a Campus Smart-Parking System assignment containing 12 tasks.

## Technologies Used
- Java
- Visual Studio Code
- Git
- GitHub

## Tasks
1. Task 1 – Classes and Objects
2. Task 2 – Data Representation
3. Task 3 – Parking Facility
4. Task 4 – Constructors
5. Task 5 – Static Members and Lifecycle
6. Task 6 – Inheritance
7. Task 7 – Method Overriding
8. Task 8 – Polymorphism
9. Task 9 – Abstraction
10. Task 10 – Encapsulation
11. Task 11 – Smart Parking System
12. Task 12 – Design Challenge

Each task folder contains Java source code and an analysis text file.

## How to Run
1. Install the Java Development Kit (JDK).
2. Open the project folder in Visual Studio Code.
3. Open a terminal in the required task folder.
4. Compile the Java file using `javac FileName.java`.
5. Run the compiled class using `java ClassName`.

Replace `FileName.java` and `ClassName` with the names of the Java file and its main class.
